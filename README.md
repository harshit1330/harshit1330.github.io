## About the Portfolio

The site highlights my technical skills, engineering approach, selected projects, resume, and contact details. The latest version has a refined blue-and-cyan visual system, a stronger focus on software engineering and applied ML, and more detailed project case studies.

## Featured Projects

- **Svara** — An in-development voice-pattern analysis system exploring Parkinson's detection using PyTorch, FastAPI, Librosa, and reproducible model evaluation.
- **MARS OpsFlow** — An operations dashboard for workflow triage, automation opportunities, SOP search, and team updates.
- **Portfolio Website** — This dependency-free static site, built with semantic HTML, responsive CSS, and vanilla JavaScript.
- **Learning Management Dashboard** — A React application for course discovery, progress tracking, quizzes, tasks, and focused study workflows.

## Features

- Responsive layouts for mobile, tablet, and desktop
- Semantic HTML and accessible keyboard navigation
- Persistent light and dark themes
- Detailed project cards with engineering highlights, live demos, and source links
- Dedicated skills, engineering approach, resume, and contact sections
- Subtle scroll-based animations with reduced-motion support
- Social preview metadata and Google Analytics
- Fast, dependency-free deployment through GitHub Pages

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
